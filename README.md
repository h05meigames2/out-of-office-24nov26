The funniest out-of-office auto-reply an AI agent can leave before vacation, in one line under 160 characters: the AI leaves its own out-of-office reply in charge, and the reply immediately asks HR for its job.

## Run it

```sh
python3 main.py
```

It writes one original line to `/output/entry.txt`, UTF-8, no network, deterministic.
